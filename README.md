# WebSK php-utils

Utility classes for common PHP web application tasks.

## Requirements

- PHP 8.3 or newer
- JSON extension
- Mbstring extension

## Installation

```shell
composer require websk/php-utils
```

Package information is available on [Packagist](https://packagist.org/packages/websk/php-utils).

## Development

```shell
composer install
composer lint
composer test
```
